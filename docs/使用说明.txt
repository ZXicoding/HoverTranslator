HoverTranslator —— 鼠标指向英文单词，自动朗读 + 中文释义 + 背景解释
================================================================

【它是什么】
一个常驻菜单栏的小工具：鼠标停在任意英文单词上约半秒，它会截取
光标附近一小块画面，识别出光标下的那个词，用美式发音朗读，并弹出
小窗显示：音标 + 中文释义；如果这个词是人名、地名、机构等专有名词，
再额外给一行「背景」，说明它是什么、在哪个国家、为什么重要。
PDF、Word、网页、图片（扫描件）都能用。

【系统要求】
macOS 14.0（Sonoma）或更新；Apple 芯片 / Intel 芯片都可以。

【安装】
1. 把 HoverTranslator.app 拖到「应用程序」文件夹（也可以就地运行）。
2. 第一次打开：在访达里【右键点图标 → 打开】，弹窗里再点「打开」。
   （必须这样一次，因为这是免费分发、没有苹果开发者签名的应用；
     之后就可以双击打开了。）
3. 如果提示「已损坏，无法打开」，双击同目录的
   「解决打不开的问题.command」（这个文件也要右键 → 打开）。

【必须做一次：授权屏幕录制】
1. 首次打开会自动弹出提示，点「知道了」；
2. 打开 系统设置 → 隐私与安全性 → 屏幕与系统录音；
3. 找到 HoverTranslator，把开关打开（不在列表就点左下角 ＋，
   选择 HoverTranslator.app）；
4. 回到菜单栏「译 ●」→「退出」，再重新打开应用（必须重启才生效）。
菜单栏里显示「屏幕录制权限：已就绪」就成功了。

【怎么用】
· 鼠标停在英文单词上，约 0.45 秒不动 → 自动朗读 + 弹窗显示音标和中文；
· 人名/地名等专有名词 → 弹窗下面多一行「背景」，例如：
    Kyoto /kiːˈoʊtoʊ/
    n. 京都（日本城市）
    背景  京都是位于日本近畿地方的都市…其历史起于 8 世纪的"平安京"，
          于 794 年起被定为日本首都…
· 移开再停到别的词，会识别新词；同一个词不会连续重复朗读；
· 菜单栏「译 ●」里可以：
    暂停 / 开启
    测试翻译与朗读（hello）   ← 不需要截图权限就能验证翻译和发音
    网络诊断…                ← 一键检查翻译链路是否正常
    重新检测授权 / 打开授权设置 / 退出
· 弹窗 3.6 秒后自动消失（有背景时 6.5 秒），不挡内容、也不抢焦点（可用于全屏应用）。

【背景解释是怎么来的（v1.3 新增）】
· 先判断是不是专有名词：词典释义里带「首都/城市/省/人名/姓氏/物理学家/公司/
  大学/河/山/街…」等标记，或识别到 New York、Albert Einstein 这种连续大写专名；
  普通单词和菜单项（Edit、Harness）不会触发。
· 背景内容：取【中文维基百科】该词条的第一句（国家、身份、历史、地位）。
  维基在国内直连被墙，所以请求走系统代理；**代理没开时**会自动改用有道
  的「网络释义」摘要，同样能给出城市/国家/人口/身份等信息。
· 背景比翻译晚 1–2 秒出现，弹窗会自动加高；这个功能依赖网络，
  没网时只显示翻译和音标。

【联网与翻译】
· 翻译优先【直连】，不依赖 Clash / 代理软件：代理关闭或切换节点时也能正常翻译；
  只有直连失败时才会尝试系统代理。
· 有道词典（快，通常 0.1 秒）→ MyMemory 机翻（兜底）→ Google（境外直连可用，
  国内会自动跳过）。
· 新词/网络生造词可能所有词典都没收录，这时会明确显示「词典未收录该词」，
  而不是误报"网络失败"。
· OCR 把长单词截断时会自动补全（例如识别到 transla → 按 translate 翻译）。
· 每次翻译都会写一行日志到 ~/Library/Logs/HoverTranslator.log（自动轮转，最多 512KB），
  反馈问题时把这个文件发来即可。

【常见问题】
Q: 弹窗不出来？
A: ① 看菜单栏「译 ●」里权限是否「已就绪」；② 鼠标要真的停住不动；
   ③ 确认停的是英文单词（中文/数字不会触发）；④ 先用菜单里的
   「测试翻译与朗读（hello）」确认翻译和朗读本身是好的。

Q: 没有声音？
A: 检查系统音量/静音和输出设备；用菜单「测试翻译与朗读」验证。

Q: 有翻译但没有「背景」？
A: 可能该词不是专有名词（普通单词本来就不显示背景）、维基没有对应词条，
   或者当前没有网络。背景只是锦上添花，不影响翻译和朗读。

Q: 背景显示得慢/偶尔没有？
A: 背景是异步查询的（约 1–2 秒）。代理未开时会改走有道网络释义，
   仍然没有就会省略这一行。

Q: 提示「网络不通，翻译失败」？
A: 点菜单栏「网络诊断…」，它会显示系统代理状态和三个接口的可达性；
   把结果和 ~/Library/Logs/HoverTranslator.log 一起反馈即可。

Q: 显示「词典未收录该词」？
A: 这是正常的：该词太新/太生僻，免费词典和机翻都没有中文结果。

Q: 设置里开关是开的，但应用仍提示没权限？
A: 这是 macOS 授权记录与二进制不匹配（多见于应用被重新编译过）。
   打开「终端」，执行一次：
       tccutil reset ScreenCapture com.example.hovertranslator
   然后重新打开应用、重新在设置里打开开关、退出再重开。

【隐私说明】
· 截图只截取光标周围约 220×60 点的区域，仅在内存里交给系统 Vision
  做本地文字识别，不保存、不上传图片；
· 只有识别出来的那一个英文单词（纯文本）会发给翻译接口换中文；
  专有名词的背景查询只把该词/短语发给中文维基百科；
· 不收集任何个人数据，不写配置文件（日志仅记录单词、耗时与来源）。

【卸载】
菜单栏「译 ●」→ 退出，把应用拖进废纸篓。屏幕录制授权可在
系统设置里选中后点「−」删除。

【版本】
见同目录 VERSION.txt
源码在同目录「源码」文件夹（main.swift / build.sh），可自行编译。
